The user wants **Diario** to contain the statistics, **Journaling** to show all the individual days, and the **Obiettivi** navigation item removed.

**Why:** The user clarified the earlier request: “Diario che deve contenere le statistiche mentre la funzione di mostrare tutte le giornate sta a Journaling.”

**How to apply:** Keep these two public destinations distinct in desktop/mobile navigation and footer. Do not put the statistics in Journaling or hide its day list behind a statistics tab. Removing the Obiettivi menu item does not authorize deleting its data or admin tools.
