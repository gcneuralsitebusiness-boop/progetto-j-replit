SECTION 6 — DIARY TEXT (redesigned rendering)
═══════════════════════════════════════════════════════

The diary text is stored as plain text with markdown-
style bold markers: **Il Corpo**, **Il Lavoro**, etc.

CURRENT: rendered as plain white text with left red
border (border-l-2). Subtitles look identical to body.

NEW RENDERING:
1. Keep the left red border-l-2 on the container.

2. Parse the text for patterns matching **...** and
   render them as styled subtitles:
   - Font: Bebas Neue (font-serif)
   - Size: 20px
   - Color: #B81D1D (primary red)
   - Uppercase
   - Margin-top: 24px (except if it's the first element)
   - Margin-bottom: 8px
   - Display: block

3. Body text between subtitles:
   - Font: Inter, 16px, color #F5F0E8, line-height 1.7
   - Max-width: 65ch (characters) for readability
   - Margin-bottom: 16px per paragraph

4. The stripDayLabel() function must still run before
   rendering (already implemented — keep it).

Implementation approach:
  Split the text by line. For each line:
  - If it matches /^\*\*(.+)\*\*$/ → render as subtitle
  - Else → render as paragraph
  
  Or use a simple regex replace to convert **text**
  into <span class="...">text</span> with the styles.
