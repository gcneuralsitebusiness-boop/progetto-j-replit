2. GRAFICI — AREA FILL + LINEE PIÙ SPESSE
═══════════════════════════════════════════

GRAFICO PESO (LineChart):
- Cambia strokeWidth da 2 a 3
- Aggiungi sotto la Line un componente <defs> 
  con linearGradient e un <Area> che riempie 
  sotto la curva con gradiente dal rosso (opacity 
  0.3) a trasparente. In Recharts si fa così:

  Sostituisci LineChart con ComposedChart (importalo)
  e aggiungi:
  <defs>
    <linearGradient id="pesoGrad" x1="0" y1="0" 
      x2="0" y2="1">
      <stop offset="0%" stopColor="#B81D1D" 
        stopOpacity={0.35} />
      <stop offset="100%" stopColor="#B81D1D" 
        stopOpacity={0} />
    </linearGradient>
  </defs>
  <Area type="monotone" dataKey="peso" 
    fill="url(#pesoGrad)" stroke="none" />
  <Line ... (il resto uguale ma strokeWidth={3}) />

- L'ultimo dot deve essere più grande (r: 5) e 
  pulsare con un'animazione CSS:
  Aggiungi in index.css:
  @keyframes pulse-dot {
    0%, 100% { r: 5; opacity: 1; }
    50% { r: 8; opacity: 0.6; }
  }
  .recharts-dot:last-of-type {
    animation: pulse-dot 2s ease-in-out infinite;
  }
  NOTA: se questo selector è troppo aggressivo, 
  usa un customDot component per l'ultimo punto.

GRAFICO SONNO (BarChart):
- Le barre devono avere un'animazione di crescita 
  dal basso. Recharts lo fa di default ma calibra:

GRAFICO BATTITO (LineChart):

4. CORRELAZIONI — MINI BAR COMPARATIVO
═══════════════════════════════════════════

Nel componente CorrelationCard, sotto i due numeri 
(firstValue e secondValue), aggiungi due barre 
orizzontali proporzionali:

<div className="mt-3 flex flex-col gap-1">
  <div className="h-1.5 bg-primary" 
    style={{ width: `${pctFirst}%` }} />
  <div className="h-1.5 bg-iron" 
    style={{ width: `${pctSecond}%` }} />
</div>

Dove pctFirst e pctSecond sono calcolati come 
percentuale relativa al maggiore dei due:
const maxVal = Math.max(
  Math.abs(firstValue ?? 0), 
  Math.abs(secondValue ?? 0)
);
const pctFirst = maxVal > 0 
  ? (Math.abs(firstValue ?? 0) / maxVal) * 100 : 0;
const pctSecond = maxVal > 0 
  ? (Math.abs(secondValue ?? 0) / maxVal) * 100 : 0;
