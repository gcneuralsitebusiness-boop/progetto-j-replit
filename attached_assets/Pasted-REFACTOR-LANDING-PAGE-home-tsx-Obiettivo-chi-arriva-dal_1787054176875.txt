DAYCARD NELLA HOME — HOOK TESTUALE
═══════════════════════════════════════════

Nelle DayCard mostrate nella sezione 
"ULTIMI GIORNI" (le ultime 3), il testo 
preview (line-clamp-3) mostra le prime 
righe del diario. Queste righe spesso 
iniziano con "GIORNO 097 —" o altri label 
tecnici che vengono già strippati da 
stripDayLabel().

Aggiungi in DayCard.tsx che quando il testo 
è presente, dopo stripDayLabel() e stripHtml(), 
prende solo la prima frase significativa 
(fino al primo punto o al primo \n):

function firstSentence(text: string): string {
  const clean = text.trim();
  const dot = clean.indexOf(".");
  const newline = clean.indexOf("\n");
  const cut = Math.min(
    dot > 0 ? dot + 1 : clean.length,
    newline > 0 ? newline : clean.length,
    120
  );
  return clean.slice(0, cut).trim();
}

Usa firstSentence(stripHtml(stripDayLabel(
  entry.testo))) come testo mostrato nella 
preview delle DayCard nella home. Questo 
mostra la prima frase vera del diario — 
quella che funziona come hook.

IMPORTANTE: questa modifica va applicata SOLO 
alle DayCard nella home (sezione "ULTIMI GIORNI"), 
NON a quelle nel journaling che mostrano 
più testo. Per distinguerle, aggiungi una prop 
opzionale a DayCard:

interface DayCardProps {
  entry: Entry;
  featured?: boolean;
  hookOnly?: boolean; // nuovo
}

Quando hookOnly={true}, mostra firstSentence.
Quando hookOnly={false} o assente, mostra 
il testo completo line-clamp-3 come adesso.

Nella home, passa hookOnly={true} alle DayCard:
<DayCard entry={entry} hookOnly />

Nel journaling, non passare hookOnly — 
comportamento invariato.
