Modifica la sezione "Articoli" del sito.

OBIETTIVO
Voglio poter incollare HTML grezzo (h1, h2, p, ul, 
li, blockquote, strong, em, a, hr) nel campo 
contenuto di un articolo e vederlo renderizzato con 
lo stile del brand, senza scrivere classi CSS a mano.

IMPLEMENTAZIONE
1. Nel form di creazione/modifica articolo, il campo 
   "contenuto" deve essere una textarea che accetta 
   HTML grezzo.
2. Il contenuto va renderizzato come HTML (non 
   escapato). Se il progetto è React, usa 
   dangerouslySetInnerHTML dentro un wrapper 
   <div class="article-body">. Se è HTML statico o 
   template engine, stampa il contenuto raw dentro 
   lo stesso wrapper.
3. Sanifica l'HTML in ingresso con DOMPurify prima 
   del render, permettendo solo questi tag: h1 h2 h3 
   p ul ol li blockquote strong em a br hr. 
   Per <a> permetti solo href, target, rel.
4. NON aggiungere classi ai tag: lo stile deve 
   arrivare dal CSS discendente di .article-body.

CSS DA CREARE
Aggiungi al foglio di stile globale un blocco 
.article-body con questi token del brand:

  --nero: #0A0A0A;
  --rosso: #B81D1D;
  --rame: #B87333;
  --testo: #E8E4DE;
  --testo-soft: #A39E97;
}

  background: var(--nero);
  font-family: 'Inter', system-ui, sans-serif;
  font-size: 1.0625rem;
  line-height: 1.75;

  margin: 0 auto;

}

}

  line-height: 1.05;

  color: var(--rame);
  margin: 3.25rem 0 1rem;

}

.article-body h2:first-child,

VINCOLI

  già presenti.

  testo resti leggibile e gli h2 non vadano a capo 
  male.
- Non cambiare nient'altro del sito: solo la pagina 
  articolo e il CSS.
