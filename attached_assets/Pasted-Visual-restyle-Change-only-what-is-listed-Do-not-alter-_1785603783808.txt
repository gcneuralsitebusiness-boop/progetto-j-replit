A5 — SIGNATURE: THE HEART RATE TRACE
═══════════════════════════════════════════

CREATE: artifacts/progetto-j/src/components/PulseTrace.tsx

An inline SVG that plots the real resting heart rate
series from the entries.

Props:
  entries: Entry[]
  variant: "hero" | "divider"

Logic:
  const points = entries
    .filter(e => e.battito != null)
    .sort((a, b) => a.numero - b.numero)
    .map(e => ({ x: e.numero, y: e.battito }));
  Return null if fewer than 2 points.

Render a single <path> as a polyline across a viewBox
sized 1000 x 120, preserveAspectRatio="none",
width 100%.

Map x from the first to the last day number across the
full width. Map y so the highest bpm sits near the top
and the lowest near the bottom, with 15% padding above
and below.

variant="hero":
  stroke: hsl(var(--primary))
  stroke-width: 1.5
  fill: none
  opacity: 0.9
  Add a small filled circle (r=3, primary) at the LAST
  point only.
  On page load, animate the path drawing itself using
  stroke-dasharray / stroke-dashoffset over 2.2s
  ease-out. Wrap in a prefers-reduced-motion check —
  if reduced motion is requested, render the path
  fully drawn with no animation.

variant="divider":
  stroke: hsl(var(--iron))
  stroke-width: 1
  opacity: 0.5
  No animation, no end dot.
  viewBox height 60 instead of 120.

PLACEMENT:

pages/home.tsx — inside the hero section, positioned
absolutely behind the "J" and the headline, spanning
the full width, vertically centred, pointer-events-none,
z-index below the text. Pass variant="hero".

  Inter, 10px, uppercase, tracking 0.25em,
  text-muted-foreground:
  "BATTITO A RIPOSO · {first} → {last} BPM"
with the two numbers in .measured and the arrow in iron.

Then replace every <div className="cut-divider" /> on
the home page with <PulseTrace entries={allEntries}
variant="divider" />.

The trace is the one memorable element of the site.
Nothing else on the page may animate on load.
