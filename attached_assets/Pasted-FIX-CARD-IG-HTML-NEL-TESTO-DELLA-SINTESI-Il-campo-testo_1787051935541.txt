FIX — CARD IG: HTML NEL TESTO DELLA SINTESI

Il campo "testo" del diario ora contiene HTML 
(es. <h2>Il Corpo</h2><p>testo</p>). 
La card IG lo stampa grezzo mostrando i tag 
visibili invece del testo pulito.

═══════════════════════════════════════════
DOVE SI TROVA IL BUG
═══════════════════════════════════════════

File: artifacts/progetto-j/src/pages/card.tsx

Funzione resolveSintesi() (righe ~26-35):
prende il campo testo e lo usa direttamente 
per costruire la sintesi. Se testo contiene 
HTML, i tag appaiono nella card.

Stessa cosa nel canvas export:
artifacts/progetto-j/src/lib/canvas-card-export.ts
il campo summary viene disegnato su canvas 
con ctx.fillText — se contiene tag HTML li 
stampa come stringa.

═══════════════════════════════════════════
FIX
═══════════════════════════════════════════

In card.tsx, la funzione resolveSintesi() 
deve strippare l'HTML dal testo prima di 
usarlo. Aggiungi questa funzione helper 
prima di resolveSintesi():

function stripHtml(html: string): string {
  // Rimuove tutti i tag HTML e decodifica 
  // le entity HTML base
  return html
    .replace(/<[^>]+>/g, " ")
    .replace(/&nbsp;/g, " ")
    .replace(/&amp;/g, "&")
    .replace(/&lt;/g, "<")
    .replace(/&gt;/g, ">")
    .replace(/&quot;/g, '"')
    .replace(/\s+/g, " ")
    .trim();
}

Poi in resolveSintesi(), dove si usa il campo 
testo, wrappalo con stripHtml():

// PRIMA (riga ~29):
const cleaned = testo 
  ? stripDayLabel(testo)
    .replace(/\*\*/g, "")
    .replace(/\s+/g, " ")
    .trim() 
  : "";

// DOPO:
const cleaned = testo 
  ? stripHtml(
      stripDayLabel(testo)
        .replace(/\*\*/g, "")
    )
  : "";

STESSO FIX NELLA DAYCARD (lista journaling)

Fix: prima di stampare entry.testo nel preview,

// PRIMA:

═══════════════════════════════════════════
SOLUZIONE PULITA — FILE CONDIVISO
═══════════════════════════════════════════

Invece di duplicare stripHtml in ogni file, 
creala in un posto solo:

File: artifacts/progetto-j/src/lib/strip-html.ts

export function stripHtml(html: string): string {
  return html
    .replace(/<[^>]+>/g, " ")
    .replace(/&nbsp;/g, " ")
    .replace(/&amp;/g, "&")
    .replace(/&lt;/g, "<")
    .replace(/&gt;/g, ">")
    .replace(/&quot;/g, '"')
    .replace(/\s+/g, " ")
    .trim();
}

Poi importala dove serve:
import { stripHtml } from "@/lib/strip-html";
